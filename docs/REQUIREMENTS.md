# 📋 System Requirements

## 1. Functional Requirements (FR)
- **FR1: User Registration/Login**: Users must be able to create accounts as Attendees or Organizers.
- **FR2: Event Discovery**: Users can search for events by title, venue, or category.
- **FR3: Booking System**: Attendees can book tickets for published events.
- **FR4: Organizer Dashboard**: Organizers can manage their events and view booking statistics.
- **FR5: Wishlist**: Users can save events to their personal wishlist.
- **FR6: Review System**: Users can rate and comment on events they have attended.

## 2. Non-Functional Requirements (NFR)
- **NFR1: Performance**: Live search results should load in under 200ms.
- **NFR2: Security**: All database queries must use Prepared Statements to prevent SQL Injection.
- **NFR3: Usability**: The UI must be responsive and work on mobile devices.
- **NFR4: Reliability**: The system should handle concurrent bookings without data loss.

## 3. User Stories
- **As an Attendee**, I want to find cultural events in Addis Ababa so I can experience local traditions.
- **As an Organizer**, I want to see how many people booked my event so I can manage venue capacity.
- **As an Admin**, I want to oversee all events to ensure they comply with platform policies.
