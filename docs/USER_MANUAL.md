# 📖 User Manual - EthioEvent Hub Premium

## 1. Getting Started
To access the platform, navigate to `http://localhost/Wep_Programming_Pro/EthioEventHub/`. For best results, use a modern browser like Chrome, Firefox, or Edge to enjoy the glassmorphism effects.

## 2. User Roles
- **Attendees**: Can discover events, wishlist favorites, book tickets, and leave star-ratings.
- **Organizers**: Can launch events, track performance with live charts, and export guest data to Excel.
- **Administrators**: Maintain global oversight of all platform activity and users.

## 3. Experience for Attendees
### 🔍 Discovery
- Use the **Instant Shuffler** on the home page to filter events by category without reloading.
- Use the **Live Search** in the navigation bar for real-time keyword matching.

### 🎟️ Booking & Feedback
- After booking, your tickets are stored in **My Bookings**.
- Once you attend an event, go to the event details page to leave a **Star Rating and Review** for the community.

## 4. Experience for Organizers
### 📈 Analytics & Management
- Your **Organizer Studio** features live charts powered by Chart.js.
- **Event Export**: Click the **"Export Attendees"** button next to any event to download a full guest list in CSV format (compatible with Excel).

### 🛠️ Creating Events
- Upload high-quality posters (`.jpg` or `.png`). Our system automatically secures and optimizes these files.

## 5. Security & Account
- **Notifications**: Check the bell icon in the top right for real-time updates on your bookings or system alerts.
- **Profile**: Keep your contact information updated to ensure you receive digital ticket confirmations.
